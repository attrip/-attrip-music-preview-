# LOCKED Decisions

These are current successful decisions. They are protected from incidental changes.

## Product concept — LOCKED
- User is the Piano player.
- Band supports the user rather than auto-playing the Piano.
- Core experience: simple controls, credible jazz/funk band feeling.

## Piano interaction — LOCKED
- Chords are user-triggered.
- One input produces approximately four-note jazz voicings.
- A/S/D/F are the current core chord controls.

## Bass source — LOCKED
- Finger Bass YR / FreePats is the current winning bass-source candidate.
- Do not replace it while investigating performance, groove or mix issues.

## Groove evidence — LOCKED
- Earlier listening favored the simpler P1/P2/P3 family over more melodic P4/P5/P6 movement.
- Prefer pocket, space and ghost-note variation over unnecessary bass-note movement.

## Current unresolved issue — NOT LOCKED
User report: **after the harmony disappears, exposed single-note material breaks immersion / feels cold.**

Do not assume the cause is Piano release. Candidate domains include Player, Groove, Source and Mix.

## Unlock Request format
Before changing a LOCKED item, document:
1. Locked item
2. Evidence that it blocks the current objective
3. Proposed replacement
4. One-variable A/B test
5. Revert condition
